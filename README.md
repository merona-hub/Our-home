# Our Home 🏠

A small phone app for our home: shared expenses, monthly bills, a shopping list and the lease.

- **Money** – add expenses, see who owes whom, settle up.
- **Bills** – Arnona, electricity, water, gas, internet, building committee (and any others). "I paid" adds it to expenses.
- **To buy** – things the home needs. Tick when it arrives; purchases go straight into expenses.
- **Contract** – lease dates, deposit, and a reminder a month before you need to notify the landlord.

Setup instructions (no coding needed): see [SETUP.md](SETUP.md).

Tech: plain HTML/CSS/JavaScript, installable as a home-screen app (PWA). Shared data is stored in Google Firebase (Firestore). Without Firebase it runs in demo mode on one device.
